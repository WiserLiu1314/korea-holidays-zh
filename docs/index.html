如何添加与理解补假

iPhone：日历 → 日历 → 添加日历 → 添加订阅日历，粘贴上面的 HTTPS 地址。若已有韩文韩国日历或旧的手动导入版，请取消勾选它们，避免重复显示。

“补假”是额外休息日，不是周末补班。普通周末不会单独列出，但落在周末的公休日仍保留。所有事件为全天事件，默认不设置提醒。具体出勤安排以所在单位为准。
